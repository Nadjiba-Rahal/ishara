# ISHARA Avatar

Avatar workspace for glTF/GLB models, sign animations, sequencing tools, and future HamNoSys/SigML adapters.

This folder must not contain redistributed third-party ALSL assets unless their license explicitly allows it.

The supplied avatar package is integrated in `apps/web/public/avatar/` and is
served as `/avatar/index.html`. It contains CWASA runtime files and SigML
assets. Verify third-party licensing before public redistribution.
